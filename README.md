## 🌐 About This Project

Welcome to my **Week 2 Cybersecurity Project**, completed as part of the **Networkwalks Cybersecurity Program**.

This repository documents my hands-on work across two practical modules, covering domain footprinting, DNS enumeration, website technology analysis, local network discovery, and network topology documentation.

## 🚀 Modules Overview

<table>
  <tr>
    <td width="50%" valign="top">
      <h3>🔎 PM1 — Footprinting</h3>
      <p><b>Environment:</b> Kali Linux</p>
      <p>Exploring domain information, DNS records, website technologies, HTTP headers, and web application firewall detection.</p>
      <p><b>🧰 Tools</b></p>
      <p>WHOIS · WhatWeb · Nslookup · cURL · Wafw00f · DNSRecon</p>
